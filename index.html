The real app is built in MIT App Inventor and connects to the cane's HC-05 (Bluetooth Classic) module. It receives one line per reading — 87,ALERT or 250,OK — splits it on the comma, shows the number, and colours the panel. This web page reproduces that same logic in JavaScript so you can see it without hardware.

How it works

Cheap, robust parts doing one job well.

1. Sense

An HC-SR04 emits a 40 kHz pulse and times the echo: distance = (echo × speed of sound) ÷ 2.

2. Confirm

Three consecutive readings must agree before alerting, so a passer-by doesn't trigger a false alarm.

3. Warn

A vibration motor (cane) or buzzer (glasses) fires locally — no phone needed for the core warning.

4. Inform

The HC-05 streams live readings to the family app for confirmation, GPS and SOS.

Design principle: the cane works without power. If the battery dies, the user still has a full-length cane. Safety never depends on a charge.
